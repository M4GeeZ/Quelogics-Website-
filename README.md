# QueLogics React Website

This package contains the React/Vite frontend only. The previous Express server and duplicate/unused source files were intentionally excluded.

## Main folders

- `src/components/Home/` — homepage sections, each in its own clearly named folder.
- `src/components/Navbar/` — active navbar JSX and CSS.
- `src/components/Footer/` — active footer JSX and CSS.
- `src/pages/` — every route-level page in its own folder.
- `src/pages/Shared/` — the two shared page layouts and the existing shared page styling.
- `src/data/` — navigation and page content.
- `src/styles/` — global variables and the existing website theme.

## Run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
